# SIORE

Sistema Inteligente de Optimización de Recursos.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicación

Sube todos los archivos de esta carpeta a un repositorio de GitHub. En Streamlit Community Cloud crea una aplicación nueva, selecciona el repositorio y usa `app.py` como archivo principal.
